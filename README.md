# usage-dashboard

Mod de Claude Code: un panel lateral con barras horizontales para los límites de uso de 5 horas y semanal.

## Instalación

En Claude Code:

```
/plugin install usage-dashboard --marketplace matiasArrebillaga/usage-dashboard-claude
```

# skills-panel

Mod de Claude Code: un panel con todas tus skills y agentes, qué hace cada uno y un botón para usarlo. Abrilo con `/skills-panel`.

```
/plugin install skills-panel --marketplace matiasArrebillaga/usage-dashboard-claude
```
